# Я Бао Завари - homepage architecture prototype

Статическая версия для GitHub Pages. Основа - предыдущая вёрстка проекта, но главная пересобрана под финальную SEO/MVP-архитектуру.

## Что изменено
- сохранён `assets/video/hero-tea-loop.mp4`;
- Hero собран как единый большой media-контейнер по логике Design Dent: видео с постером занимает весь фон внутри скруглённой рамки с box-shadow, а текст и кнопки лежат слева поверх видео;
- H1 закреплён за локальным интентом «чайная в Челябинске на Кировке»;
- новая навигация: Чай, Церемония, Меню, О чайной, Блог, Контакты;
- главная пересобрана по пользовательским сценариям: обычный визит, церемония, встреча вдвоём/с друзьями;
- убран SEO-акцент на чайной посуде;
- убраны с главной неподтверждённые события, сертификаты, цены, график и отдельная страница отзывов;
- FAQ перенесён внутрь главной;
- добавлены локальный блок Кировки, контентный hub и новая финальная CTA-секция;
- JSON-LD на главной оставляет только подтверждённые данные без непроверенного графика и телефона.

## Важное перед production
1. Унифицировать NAP: в проекте и 2ГИС используется «Кирова, 94», в Яндекс Картах ранее отображался «94А».
2. Подтвердить телефон и график до вывода на новой главной и в Schema.
3. Подключить реальную серверную отправку формы. Сейчас форма - UI-прототип и ничего не отправляет.
4. Заменить юридические плейсхолдеры в `privacy.html` и `consent.html`. Эти страницы временно `noindex`.
6. Следующий этап - отдельные маршруты `/chaynaya-ceremoniya/`, `/menu/`, `/blog/` и SEO-статьи из утверждённой архитектуры.
